# 검사 문제 정의 — 실시간 로고 부착 검사

> 작성: 2026-10-28 · 상태: 초안 (촬영·측정 후 수정)

## 1. 왜 이 검사를 하나요?

1~3일차 방식(Area Ratio)은 "물체가 있는가"는 잘 판단하지만,
**크기가 같고 모양만 다른 라벨·로고**는 구분하기 어렵다.
4일차에서 배운 특징점 매칭(SIFT + RANSAC + Homography)으로
**정해진 로고가 실제로 있는지, 제대로 붙어 있는지**를 실시간 영상에서 판정한다.

## 2. 검사 정의

| 항목 | 내용 |
|---|---|
| 검사 대상 | 제품 포장지의 특정 로고 (예: 광천김 KC + (주)광천김 로고) |
| 입력 | IP Webcam 실시간 Frame, 640×480, 휴대폰 고정 |
| 기준 이미지 | 같은 IP Webcam으로 찍은 정면 사진에서 로고 영역 Crop |
| 측정값 | FOUND 여부, Good Match 수, Inlier 수, Inlier Ratio, 사각형 중심·각도 |
| 출력 | OK / NG / CHECK + 이유 → WebSocket으로 여러 화면에 전송 |

## 3. 판정 상태

| 상태 | 의미 | 예시 이유 |
|---|---|---|
| OK | 기준 로고가 있고 조건을 만족 | — |
| NG | 로고가 없거나 다른 제품 | `NG_LABEL_MISSING` |
| CHECK | 특징점이 부족해 판정 불안정 | `CHECK_LOW_INLIER` |
| (2단계) NG | 위치·각도가 허용 범위 밖 | `NG_LABEL_POSITION`, `NG_LABEL_ANGLE` |

> 기준값(Inlier Ratio, 허용 각도 등)은 지금 정하지 않는다.
> Calibration 사진을 측정한 뒤 정상/불량 분포를 보고 결정한다. (3·5일차 원칙)

## 4. 범위

- **1단계 (필수)**: 로고 있음 / 없음 → 사진 Test → 실시간 → WebSocket
- **2단계 (확장)**: 위치·각도 허용 범위 판정, 여러 화면 동시 모니터

## 5. 촬영 계획

| 구분 | 상태 | 목표 장수 |
|---|---|---|
| Reference | 정면, 정상 위치 | 1 |
| Calibration OK | 위치 조금 이동 / 약간 회전 / 거리 조금 변화 | 각 2~3 |
| Calibration NG | 로고 가림 / 포장지 뒤집기 / 다른 제품 / 빈 화면 | 각 2~3 |
| Test OK / NG | 위와 비슷하게 **새로** 촬영 | 각 5 |

촬영 원칙
- 같은 카메라(IP Webcam), 같은 해상도(640×480), 휴대폰 고정
- 한 장에 한 가지 조건만 바꾸기
- Calibration과 Test는 따로 촬영 (기준을 만든 사진으로 성능을 말하지 않음)
- 로고가 화면 가장자리에 붙지 않게 (4일차 Template 경계 문제)

## 6. 예상 한계

- 비닐 반사가 심하면 특징점이 줄어 CHECK가 많아질 수 있다.
- 로고가 화면에서 너무 작으면(멀리서 촬영) Matching이 불안정하다.
- 비슷한 글자가 다른 위치에도 있으면 잘못된 Match가 섞일 수 있다 → RANSAC으로 확인.
